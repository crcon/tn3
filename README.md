# 常州天宁独立储能电站 · V5 三维实景

本目录为 V5 交互模型的 GitHub Pages 静态发布版本。内容包括储能站、郑陆 220kV 变电站、西侧接入线路、263 栋周边建筑、54 处水塘及河渠，以及 8 节和谐号风格动态列车。

## 访问与操作

部署到 GitHub Pages 后，在浏览器打开该仓库的 Pages 地址。页面支持两站总览、电站鸟瞰、电站总平、郑陆变电站、场址俯视、高铁跨越、村落近景、水塘近景，共 8 个预设视角。

拖动可旋转，滚轮可缩放，右键拖动可平移；可以切换接入线路、选址范围、标注和绿化，暂停列车、自动环绕、切换充放电方向。点击“保存当前视角”会直接下载 3840 × 2160 PNG，不需要服务器保存接口。

## 文件与加载

- `index.html` 为入口；`assets/` 包含本地脚本、完整 V5 场景与三张材质图片，不依赖第三方 CDN。
- 航拍原图保持 8256 × 5431 像素，材质图片未缩小或重新压缩。
- 支持的浏览器优先下载约 5.98 MB 的无损 gzip 场景；不支持流式解压或解压失败时自动回退到原始 JSON 分片。
- 大文件仅作无损网络分片：8K JPEG 分为 6 片，原始 JSON 分为 4 片，每片不超过 8 MiB；浏览器最多同时下载 3 片，按顺序合并原始字节后使用。JPEG 通过 `image/jpeg` Blob URL 交给渲染器，未进行重采样。
- `release-manifest.json` 同时保留分片 SHA-256 与完整原件 SHA-256，支持浏览器在安全上下文内校验拼接结果。
- 所有资源使用相对路径，可部署在 `/tn3/` 等项目路径中。
- 资源文件名带内容指纹，更新入口后可正确加载对应版本。
- `release-manifest.json` 记录来源 SHA-256、场景数量及发布文件校验信息。
- `.nojekyll` 用于直接发布静态文件；`THIRD_PARTY_LICENSES.txt` 保留 Three.js 许可。

高清模型首次加载会下载较大的航拍底图，建议使用较新的桌面浏览器和稳定网络。浏览器须启用 WebGL。本站未包含 Rhino、Blender、交付压缩包或本地工作目录。

## 建模范围

项目规模为 200MW / 800MWh，排布图配置电池容量为 880MWh；模型包含 176 个电池舱与 44 组 PCS。建筑高度和立面为可视化推定；模型用于汇报与方案沟通，非测绘、施工或净距验算成果。线路和铁路跨越需以正式设计核定为准。
